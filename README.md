# Slovíčka

PWA для изучения словацкого — аналог Anki, заточенный под iPhone: интервальное повторение (SM-2),
четыре режима тренировки, импорт колод `.apkg`, статистика с серией дней, тренажёр спряжений и падежей.
Работает офлайн, данные хранятся на устройстве (IndexedDB) и по желанию синхронизируются через Firebase.

Без фреймворка и без сборки: чистые HTML/CSS/ES-модули, все библиотеки и шрифты лежат в репозитории.

## Что умеет

| Раздел | Что внутри |
|---|---|
| **Učiť sa** | счётчики «nové / v učení / opakovanie», выбор колоды и режима, кнопка «Začať», серия дней, напоминание о бэкапе раз в неделю |
| **Режимы** | **Kartičky** (показать ответ → оценка), **Písanie** (ввод с проверкой диакритики и панелью `á ä č ď …`), **Test** (4 варианта), **Časovanie a pády** (формы глаголов и падежи) |
| **SRS** | SM-2 с шагами 1 мин → 10 мин → 1 день; оценки Znova / Ťažké / Dobré / Ľahké с интервалом под каждой кнопкой; лимиты новых/повторений в день |
| **Slovník** | все слова, поиск без учёта диакритики, фильтры, «+» — добавить неактивное слово в обучение, «+N случайно / по порядку» |
| **Импорт Anki** | `.apkg` прямо в браузере: `collection.anki21b` (zstd), `anki21`, `anki2`; HTML чистится, картинки — по галочке |
| **Štatistiky** | серия дней, сегодня (повторено / новых / точность / время), тепловая карта за 26 недель, распределение карточек, прогноз на 7/30 дней, ошибки в диакритике |
| **Nastavenia** | язык SK/RU, тема, «Efekty CRT», лимиты, шаги SM-2, аккаунт и синхронизация, бэкап, импорт, редактор таблиц форм |

### Как проверяется ответ в «Písanie»

- совпало полностью → **Dobré**;
- буквы верные, но диакритика нет (`pätnast` вместо `pätnásť`) → **Ťažké**, неверные буквы подсвечиваются;
- иначе → **Znova**. Любую оценку можно выбрать вручную («я опечатался»).
- Игнорируются регистр, лишние пробелы, концевая точка, `ё/е`. Несколько ответов — через `;` или `/`;
  пояснения в скобках необязательны (`(ты) говоришь` принимает и `говоришь`); короткие синонимы через запятую
  (`жить, проживать`) принимаются по отдельности.

### Грамматика: данные не проверены

`data/grammar.json` — 45 частых глаголов A1 (настоящее время) и 34 существительных по 12 образцам склонения
(chlap, hrdina, dub, stroj, žena, ulica, dlaň, kosť, mesto, srdce, vysvedčenie, dievča).
**Всё сгенерировано автоматически и помечено `verified: false` («neoverené»)** — проверь с преподавателем.
Исправлять и отмечать «проверено» можно прямо в приложении: *Nastavenia → Tabuľky tvarov*.
Генератор стартового набора: `scripts/gen-grammar.py`.

## Запуск локально

Нужен Node.js 20+ (только для локального сервера и тестов — самому приложению Node не нужен).

```bash
npm install
```

```bash
npm run serve
```

Открыть http://localhost:8787. Service Worker работает только на `localhost` или `https`, поэтому просто открыть
`index.html` файлом не получится.

## Деплой на GitHub Pages

Сборки нет — Pages раздаёт файлы прямо из ветки `main`.

1. Перед коммитом обнови список файлов для офлайн-кэша и версию (иначе на iPhone не придёт обновление):
   ```bash
   npm run sw
   ```
   Если забыть — `npm test` упадёт с подсказкой (то же проверяет GitHub Action при пуше).
2. Закоммить и запушить в `main`.
3. Первый раз: *Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`*.
   Адрес будет `https://<ник>.github.io/slovicka/`.

Когда выходит новая версия, в приложении появляется плашка **«Je dostupná nová verzia — obnoviť»**.

## Установка на iPhone

1. Открыть адрес приложения в **Safari** (именно Safari, не Chrome).
2. *Поделиться* → **«На экран „Домой“»** → *Добавить*.
3. Запускать с иконки — откроется на весь экран, без адресной строки, работает офлайн.

Первый запуск лучше сделать с интернетом: Service Worker скачает все файлы (~1,5 МБ), дальше сеть не нужна
(кроме синхронизации).

## Бэкап (обязательно!)

iOS может стереть данные сайта, если приложением долго не пользоваться или мало места.

- *Nastavenia → Exportovať zálohu (JSON)* — на iPhone откроется «Поделиться»: сохрани в «Файлы» / iCloud Drive.
  Галочка «Aj s obrázkami» добавляет картинки (файл станет больше).
- *Obnoviť zo zálohy* — выбрать файл; **Zlúčiť** (объединить: берутся более свежие записи) или **Nahradiť všetko**.
- Раз в неделю на главном экране появляется напоминание.
- При включённой синхронизации облако — это тоже копия, но JSON-бэкап всё равно полезен.

## Синхронизация через Firebase (необязательно)

Основная база — на устройстве. Firebase — облачная копия и мост между устройствами: отправляются только
изменения, при открытии читается только то, что изменилось с прошлого раза (бесплатного тарифа Spark хватает
с большим запасом). Вход — email + пароль: он надёжно работает в PWA «на экране Домой» (вход через Google там
часто ломается).

**Картинки не синхронизируются** — для Cloud Storage Firebase сейчас нужен платный тариф Blaze. Они остаются
на устройстве и в JSON-бэкапе.

### Настройка (≈10 минут, один раз)

1. https://console.firebase.google.com → *Add project* (Google Analytics не нужен).
2. *Build → Authentication → Get started → Sign-in method → Email/Password → Enable*.
3. *Build → Firestore Database → Create database* → регион `europe-central2 (Warsaw)` → *Start in production mode*.
4. *Firestore → Rules* — вставить содержимое `firestore.rules` → *Publish*.
   Правила пускают каждого пользователя только к его данным `users/{uid}/…`.
5. *Project settings (шестерёнка) → General → Your apps → Web (`</>`)* → зарегистрировать приложение
   (Hosting не нужен) → скопировать объект `firebaseConfig`.
6. Вставить его в `js/firebase-config.js`:
   ```js
   export const firebaseConfig = {
     apiKey: '...',
     authDomain: '....firebaseapp.com',
     projectId: '...',
     appId: '...',
   };
   ```
   Этот ключ по задумке Firebase **публичный** (он всё равно виден в браузере) — данные защищают правила из
   шага 4. Для спокойствия можно ограничить ключ: Google Cloud Console → *APIs & Services → Credentials* →
   ключ → *Website restrictions*: `https://<ник>.github.io/*` и `http://localhost:8787/*`.
7. `npm run sw`, коммит, пуш. В приложении: *Nastavenia → Účet a synchronizácia → Vytvoriť účet*.

Синхронизация запускается сама: при входе, через ~20 секунд после изменений, при появлении сети,
при сворачивании приложения и после каждой сессии. Есть кнопка «Synchronizovať teraz».

Если войти на устройстве, где уже есть локальные слова, они объединятся с аккаунтом. Конфликты решаются
по времени: побеждает более поздняя правка.

## Мотивация: XP, уровни, значки, эффекты

- **XP** за каждый ответ (больше — за Písanie и грамматику, бонус за новые слова и комбо), **уровни** с титулами
  (Nováčik → Turista → … → Legenda). XP хранится в журнале ответов, поэтому одинаков на всех устройствах.
- **Комбо** верных ответов подряд (×5, ×10 … с всплывающей подсказкой и звуком).
- **Дневная цель** — кольцо на главном экране (по умолчанию 20 карточек), при выполнении — маленький салют.
- **23 значка** (серии, комбо, «Čistá diakritika», «Nočná sova», уровни…) — во вкладке Štatistiky.
- **Слово дня** на главном экране, «загрузка терминала» при первом открытии за день.
- Эффекты: карточка «включается» как ЭЛТ-экран, ответ печатается по буквам, фосфорные частицы в конце сессии.
- Звуки синтезируются (без файлов) и уважают беззвучный режим iPhone.
- Всё выключается: *Nastavenia → Motivácia a pripomienky → Animácie / Zvuky*; системное «Уменьшение движения»
  тоже учитывается.

### Настройка push (один раз, ≈5 минут)

Push на iPhone работают только с иконки «На экране Домой» (iOS 16.4+) и требуют входа в аккаунт (Firebase).

```bash
npm run push:setup
```

Скрипт создаст VAPID-ключи: публичный запишет в `js/push-config.js`, приватный положит в секреты GitHub
(`VAPID_PRIVATE_KEY`) — на экран он не выводится. Затем:

1. Firebase Console → шестерёнка → *Project settings → Service accounts → Generate new private key*.
2. Положить ключ в секреты и удалить файл:
   ```bash
   gh secret set FIREBASE_SERVICE_ACCOUNT < путь/к/файлу.json
   ```
3. Опубликовать обновлённые правила `firestore.rules` в консоли (добавлены подписки `users/{uid}/push`).
4. `npm run sw`, коммит, пуш.
5. В приложении (открытом с иконки): *Nastavenia → Motivácia a pripomienky → Zapnúť upozornenia*.

Проверить без отправки: GitHub → Actions → *reminders* → *Run workflow* с `dry_run = 1`.
Расписание GitHub бывает с опозданием до ~30 минут — правила это учитывают (окно 2 часа).
В публичном репозитории расписание отключается после 60 дней без коммитов — тогда включи его во вкладке Actions.

## Импорт колод Anki

*Slovník → Anki* (или *Nastavenia → Importovať balíček Anki*) → выбрать `.apkg`.
На экране превью: сколько заметок, первые 10, какое поле словацкое, какое русское (угадывается по кириллице),
в какую колоду. По умолчанию слова попадают в **Slovník как неактивные** — учить их начнёшь, только когда
добавишь в обучение (по одному «+» или пачкой). Дубли (тот же словацкий + русский) пропускаются.

Если Anki пишет в колоде «Please update to the latest Anki version» — экспортируй в Anki с галочкой
*Support older Anki versions*. Новый формат `anki21b` (zstd) тоже поддерживается.

Файлы `.apkg` в репозиторий не попадают (`.gitignore`).

## Тесты

```bash
npm test
```

Юнит-тесты (встроенный `node --test`): SM-2 и очередь, сравнение ответов с диакритикой, дистракторы,
разбор `.apkg` (синтетические колоды всех форматов + твоя реальная колода из `Downloads`, если она там есть),
статистика и серия, формат бэкапа, данные и упражнения грамматики, актуальность `sw.js`.

```bash
npx playwright install webkit chromium
```

```bash
npm run shots
```

Скриншоты в мобильном вьюпорте 390×844 (WebKit — движок Safari) в папку `screenshots/` + проверка ошибок
консоли. Отдельный сценарий: `npm run shots -- chromium import`.
Примечание: тестовая сборка WebKit под Windows пишет в IndexedDB очень медленно (импорт 1300 слов ~40 с);
в Chromium и на настоящем iPhone это доли секунды.

```bash
npm run test:sync
```

Синхронизация на локальном эмуляторе Firebase (нужна Java): два «устройства», правки, удаления, конфликт,
проверка правил доступа.

## Структура

```
index.html, manifest.webmanifest, sw.js   — оболочка PWA и офлайн-кэш
css/       base.css (токены, CRT), components.css, views.css, fonts.css
js/
  app.js          точка входа: таб-панель, роутер, service worker
  router.js       hash-маршруты (#/learn, #/dict, …)
  db.js           IndexedDB (idb) + outbox для синхронизации
  store.js        колоды, слова, карточки, журнал
  srs.js          SM-2 (чистые функции)        queue.js   очередь сессии и лимиты
  compare.js      проверка ответа и диакритики textutil.js снятие диакритики, нормализация
  import-apkg.js  разбор .apkg                 backup*.js экспорт/импорт JSON
  grammar*.js     тренажёр форм                stats-calc.js, charts.js  статистика
  sync.js         Firebase                     i18n.js    тексты SK/RU
  views/          экраны                       modes/     режимы тренировки
data/grammar.json  таблицы форм (verified: false)
vendor/            idb, JSZip, sql.js (WASM), fzstd, Firebase — локально, без CDN
fonts/             JetBrains Mono (интерфейс), Inter (слова) — latin, latin-ext, cyrillic
scripts/           serve, gen-sw, build-vendor, make-icons, screenshots, e2e-sync, gen-grammar
tests/             юнит-тесты
```

Обновить библиотеки: `npm update`, затем `npm run vendor` и `npm run sw`.
